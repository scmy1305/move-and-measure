# Move & Measure

Public pages for the Move & Measure iPhone app (kettlebell and strength training log).

- `consent.json`: where the app asks before sharing anonymous usage data. `{"optInRegions":"all"}` means it asks everywhere. A list such as `["GB","FR"]` means it asks there and is on by default elsewhere (always with an off switch in Settings). The app reads it on launch.
- `index.html`: the home page. Privacy policy and support pages to follow.

The app itself is in a separate private repository.
